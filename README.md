# ヘルスきち 🌙

摩擦ゼロ健康トラッキング & AI週次コーチング PWA。
1日の入力は合計10秒以内。AIは週1回だけ、説教ではなく「来週の小さな実験1つ」を提案します。

## 使い方(最短)

1. GitHub Pages を有効化(Settings → Pages → Branch: main / root)して公開URLを開く
2. Chromeのメニューから「ホーム画面に追加」→ アプリとしてインストール
3. 設定タブで Gemini APIキーを登録(「保存して接続を確認」まで押す)
4. 寝る前に 🌙おやすみ を1タップ。朝はアプリを開くだけで睡眠が自動記録されます

ローカルでの動作確認は `python3 -m http.server` などで配信して開いてください
(Service Worker のため file:// では一部機能が動きません)。

## 機能

- **すいみん**: 夜1タップ+朝タップゼロの準自動記録。24時間ダイヤルで就寝→起床を可視化
- **きろく**: 食事(チップ編集可)・☕コーヒー・🏢階段・🚶散歩を1タップ。取り消しはトーストから
- **きぶん**: 20時以降に3択1タップ
- **AI週次レポート**(Gemini): 今週のパターン+来週の実験1つ+前週実験の検証
- **履歴**: 睡眠バー/コーヒー時刻散布(21時ライン付き)/気分の推移
- データはすべて端末内(localStorage)。エクスポート/インポート対応
