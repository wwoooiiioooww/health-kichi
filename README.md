# ヘルスきち 🌙

摩擦ゼロ健康トラッキング PWA。
**1日の入力は6〜7タップ。** 記録する項目は設定でON/OFFでき、OFFにしても過去の記録は消えません。

## 使い方(最短)

1. GitHub Pages を有効化(Settings → Pages → Branch: main / root)して公開URLを開く
2. Chromeのメニューから「ホーム画面に追加」→ アプリとしてインストール
3. 寝る前に 🌙おやすみ を1タップ。朝はアプリを開くだけで睡眠が自動記録されます
4. (任意) 設定タブで Gemini APIキーを登録すると、AIによる要約が使えます

ローカルでの動作確認は `python3 -m http.server` などで配信して開いてください
(Service Worker のため file:// では一部機能が動きません)。

## 記録する項目(既定の最小構成)

相関を見るのに必要な軸だけをONにしてあります。軸を増やすほど偶然の相関が混ざるため、
**削るのは楽をするためだけでなく、レポートの精度のため**でもあります。

| 項目 | 入力 | 役割 |
|---|---|---|
| 睡眠時間 | 🌙1タップ + 自動推定 | 原因側の主軸 |
| 眠りの質 | 朝1タップ(3段階) | 睡眠の主観評価 |
| 食事の重さ | 食べたら1タップ(軽め/ふつう/がっつり) | 眠気を説明する原因側 |
| 眠気 | 夜1タップ(0-3) | 結果側 |
| イラッと | 夜1タップ(0-3) | 結果側 |
| 今日の運動量 | 夜1タップ(0-3) | 原因側 |

### 設定 → 表示する項目 で戻せるもの

21時以降のコーヒー / きぶん / はかどり / 食事の種類・お店 / 運動チップ / メモ /
週の目標とふりかえり / AIレポート

すべて**隠しているだけ**で、データは残ります。ONに戻せば過去の記録もそのまま表示されます。

## わかったこと(相関レポート)

「アドバイス」ではなく「レポート」。直近30日から、**固定の3本だけ**を層別比較で出します。

- 睡眠時間 → その日のイラッと
- 21時以降のコーヒー → その夜の睡眠
- 食事の重さ → その日の眠気

設計上の約束:

- **計算はこの端末で完結する。AIには計算させない。** LLMに平均を出させると毎回数字が揺れて検証できないため、
  AIの役割は「出た数字を日本語で読み上げる」だけに限定している(設定→AIレポート、既定OFF)
- **相関係数(r)は出さない。** n=30では誤差が大きく、読んでも行動に繋がらない。
  代わりに「Aだった日 vs Bだった日」の平均を並べる
- **足りなければ黙る。** 各群5日未満、または睡眠時間のばらつきが30分未満なら数字を出さず、
  「あと何日で出せるか」だけを表示する
- **総当たりで相関を探さない。** 組み合わせを増やすほど偶然の一致が混ざるため、見るのは3本に固定する

## その他の機能

- **からだの調子**: 不調をオンデマンドで記録。レポートで「乱れた週」の説明に使う
- **健診結果**: テキスト貼り付け or 画像をGeminiで整理して保存(年1回・任意)
- **履歴**: 睡眠バー / コーヒー時刻の散布(21時ライン付き) / こころの推移
- データはすべて端末内(localStorage)。エクスポート/インポート対応

## 構成

```
index.html            アプリ本体(UI)
core.js               ロジック層(UI非依存・Nodeでテスト可能)
sw.js / manifest.webmanifest / icon-*.png   PWA一式
tests/core.test.js    テスト(node tests/core.test.js)
CLAUDE.md             プロジェクト憲法(AI協働用)
```

過去バージョン(全機能入りのv9)は `archive/v9-full-input` ブランチに保存してあります。

## テスト

```bash
node tests/core.test.js   # 95 passed を確認
node --check core.js
```

## 設計原則

入力させたら負け / 観測が先・介入は後 / 説教禁止・仮説提案型 / 折れても責めない /
推定できないなら null / 消すのではなく隠す / ローカル完結。
詳細は `CLAUDE.md` と `.claude/skills/` を参照。
