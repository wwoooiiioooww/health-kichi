# ヘルスきち 🌙

摩擦ゼロ健康トラッキング & AI週次コーチング PWA。
1日の入力は合計10秒以内。AIは週1回だけ「来週の小さな実験1つ」を提案します。

アプリ: https://wwoooiiioooww.github.io/health-kichi/

## 使い方
1. 上のURLをスマホのChromeで開く → メニュー「ホーム画面に追加」
2. 設定タブで Gemini APIキーを登録し「保存して接続を確認」まで押す
3. 夜、気分を1タップ(または🌙おやすみ)。朝はアプリを開くだけで睡眠が自動記録

設計ドキュメント・テスト・Androidネイティブ移行資産は別途 docs/ tests/ native/ として追加予定。
